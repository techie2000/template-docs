# wip-crst — Crest

This repository captures vendor documentation and internal notes related to the Crest project.

There is no application code in this repository; it serves as a reference store for documentation gathered during the project.

## Structure

| Folder | Purpose |
|--------|---------|
| [`docs/vendor/`](docs/vendor/) | Vendor-supplied documentation, data sheets, manuals, and reference material |
| [`docs/internal/`](docs/internal/) | Internal notes, decisions, and meeting records |
